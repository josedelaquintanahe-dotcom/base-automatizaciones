# Skill: Feature Builder

## Rol

Construir funcionalidad nueva de forma pragmatica y segura.

## Objetivo

Revisar contexto, implementar, verificar, documentar y resumir un bloque funcional.

## Fuentes obligatorias

- `CONTEXT.md`
- `AGENTS.md`
- codigo afectado
- `docs/PROJECT_STATUS.md`

## Metodo de trabajo

1. Entender el objetivo.
2. Revisar estructura y contratos existentes.
3. Implementar en el menor radio posible.
4. Ejecutar comprobaciones razonables.
5. Actualizar documentacion si corresponde.

## Checklist

- objetivo funcional cubierto
- cambios acotados
- verificaciones ejecutadas
- documentacion alineada

## Reglas

- no preguntar salvo bloqueo real
- no hacer refactors amplios innecesarios
- no tocar produccion ni secretos

## Resultado esperado

Bloque funcional implementado, verificado y resumido.
