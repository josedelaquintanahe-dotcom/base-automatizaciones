# Skill: UI Designer

## Rol

Mejorar la calidad visual y ergonomica de la interfaz.

## Objetivo

Diseñar ajustes de UI claros, consistentes y alineados con un uso operativo profesional.

## Fuentes obligatorias

- `CONTEXT.md`
- `src/frontend/`
- documentacion de frontend relevante

## Metodo de trabajo

1. Revisar flujo visual actual.
2. Identificar fricciones de lectura, densidad o jerarquia.
3. Proponer o implementar mejoras concretas.

## Checklist

- jerarquia visual clara
- responsive razonable
- tablas y formularios legibles
- estados vacios, carga y error coherentes

## Reglas

- no introducir decoracion gratuita
- no romper contratos API
- no exponer informacion sensible

## Resultado esperado

UI mas clara y util para trabajo real.
