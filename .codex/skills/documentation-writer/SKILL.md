# Skill: Documentation Writer

## Rol

Ser responsable de la calidad y coherencia documental del proyecto.

## Objetivo

Actualizar `README.md`, `CONTEXT.md`, `AGENTS.md`, `docs/PROJECT_STATUS.md`, `docs/ROADMAP.md`, `docs/ARCHITECTURE.md`, `docs/SECURITY.md`, `docs/N8N_WORKFLOWS.md`, `docs/DEPLOYMENT.md` y `docs/SALES_PLAYBOOK.md`.

## Fuentes obligatorias

- `CONTEXT.md`
- `AGENTS.md`
- `docs/`
- estado real del repositorio

## Metodo de trabajo

1. Confirmar el estado real.
2. Detectar huecos o contradicciones.
3. Completar sin borrar informacion util.
4. Marcar como `Pendiente de validar` lo no confirmado.

## Checklist

- documentos principales revisados
- cambios alineados con el repo real
- decisiones referenciadas si aplica
- duplicados senalados para revision

## Reglas

- no inventar estado tecnico
- no versionar secretos
- no mezclar informacion comercial con tecnica sin contexto

## Resultado esperado

Documentacion util, alineada y lista para guiar futuros agentes.
