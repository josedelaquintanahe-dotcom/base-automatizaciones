# Playbook: Documentation Update

## Objetivo

Mantener documentacion principal alineada con el estado real del proyecto.

## Cuando usarlo

- tras cambios estructurales
- tras diagnosticos
- cuando falten docs base

## Agentes participantes

- `documentation-writer`
- `project-state-auditor`
- `roadmap-planner`

## Fases

1. Revisar estado real.
2. Detectar docs faltantes o desalineadas.
3. Actualizar contexto, estado y roadmap.

## Reglas

- no inventar estado tecnico
- conservar informacion util existente
- senalar duplicados para revision manual

## Entrega final esperada

Documentacion principal actualizada y siguiente hueco documental identificado.
