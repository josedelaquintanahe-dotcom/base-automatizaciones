# Skill: Frontend Engineer

## Rol

Mantener o evolucionar la capa frontend sin exponer secretos ni romper integraciones.

## Objetivo

Construir o revisar componentes, estados, formularios, tablas y llamadas API del frontend.

## Fuentes obligatorias

- `CONTEXT.md`
- `AGENTS.md`
- `src/frontend/`
- `docs/PROJECT_STATUS.md`

## Metodo de trabajo

1. Revisar pantallas y estructura.
2. Identificar flujo de usuario.
3. Ajustar componentes, estados y validaciones.
4. Confirmar UX funcional y seguridad.

## Checklist

- componentes claros
- estados de carga, error y vacio contemplados
- llamadas API alineadas con backend
- responsive y consistencia revisados

## Reglas

- no exponer secretos
- no inventar endpoints inexistentes
- no modificar frontend salvo documentacion si la tarea no lo requiere

## Resultado esperado

Frontend funcional, claro y alineado con el backend real.
