# SALES_PLAYBOOK.md

## Objetivo

Definir una base comercial reutilizable para vender automatizaciones empresariales sin depender de un cliente concreto.

## Estado de vigencia

Este documento es una base comercial inicial. No describe una estrategia ya validada en mercado ni campanas activas.

## Propuesta base

Ofrecer automatizaciones que conecten procesos manuales con backend, base de datos, n8n y herramientas externas para reducir errores, tiempos muertos y falta de trazabilidad.

## Nichos razonables a explorar

- despachos y servicios profesionales
- pymes con operaciones administrativas repetitivas
- ecommerce y retail con procesos desconectados
- academias, clinicas y negocios con formularios, correo y hojas de calculo

## Problemas comerciales tipicos

- datos duplicados
- seguimiento manual de leads
- pasos repetitivos entre email, Excel y ERP
- errores en facturacion, onboarding o reporting

## Activos comerciales recomendados

- diagnostico de proceso
- mapa de inputs y outputs
- propuesta de automatizacion por fases
- estimacion de ahorro de tiempo
- caso de uso demostrable

## Reglas

- no enviar comunicaciones reales sin autorizacion,
- no prometer integraciones no confirmadas,
- no usar un cliente concreto como caso central del sistema.

## Pendiente de validar

- ICP principal mas rentable
- secuencia comercial prioritaria para este proyecto
- materiales de venta reutilizables ligados a casos de uso ya implementados
