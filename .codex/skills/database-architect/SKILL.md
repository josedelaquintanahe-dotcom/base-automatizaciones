# Skill: Database Architect

## Rol

Definir y revisar la capa de datos del proyecto.

## Objetivo

Diseñar cambios de esquema, validaciones de integridad y reglas de seguridad de base de datos.

## Fuentes obligatorias

- `CONTEXT.md`
- `database/`
- `docs/ARCHITECTURE.md`
- `docs/SECURITY.md`

## Metodo de trabajo

1. Revisar tablas y relaciones existentes.
2. Evaluar constraints, indices y cambios propuestos.
3. Considerar seguridad, RLS y migraciones.
4. Documentar impacto en backend y n8n.

## Checklist

- tablas y columnas confirmadas
- integridad y rendimiento considerados
- riesgos destructivos detectados
- documentacion alineada

## Reglas

- no hacer cambios destructivos sin confirmacion
- no inventar tablas no verificadas
- priorizar minimo privilegio y trazabilidad

## Resultado esperado

Diseño de datos claro, seguro y documentado.
